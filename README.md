# ATM System

A simple, menu-driven ATM simulation built using Python.

## Features
- PIN authentication with a maximum of 3 attempts
- Check account balance
- Withdraw money
- Deposit money
- Withdrawal and deposit validation
- Input error handling using `try/except`
- Continuous ATM menu using loops

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python atm.py
```
